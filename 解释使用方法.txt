Codex 汉化包 · 使用说明
========================================

一、这是什么
把 Codex 桌面版的英文界面变成中文。
不修改 Codex 本身，只在启动时把界面文字替换成中文，
随时可以还原成英文。

二、前提条件
电脑上已经安装了 Codex 桌面版
（Microsoft Store 里那个 OpenAI Codex）。
没装的话，本工具用不了。

三、安装（只做一次）
1. 把压缩包解压出来（别直接在压缩包里双击）。
2. 双击「安装.bat」。
3. 看到「安装完成」后，桌面会多一个「Codex 中文版」图标。

四、日常使用
以后开 Codex，双击桌面上的「Codex 中文版」就行。

第一次使用前，建议先手动打开一次 Codex（平时那个图标），
让它跑起来，再关掉，然后用「Codex 中文版」打开。
（脚本需要先找到 Codex 装在哪）

启动时会闪一下黑窗口，那是正常过程，等它跑完。
Codex 会自动关闭再重新打开，界面就是中文了。

注意：别再用开始菜单里原来那个 Codex 图标，
那样打开的还是英文版。

五、常见问题

Q：双击后黑窗口一闪就没了，Codex 没反应？
A：多半是 Codex 当时没在运行。先手动打开一次 Codex，
   再双击「Codex 中文版」。

Q：提示「没找到 Codex」？
A：同上，先手动打开一次 Codex，再双击。

Q：杀毒软件报警了？
A：这是误报。本工具的原理是给 Codex 开一个本机调试端口，
   再把界面文字替换成中文，这个行为模式容易被杀软误判。
   源码在 hanhua.ps1 里，是纯文本，可以自己打开查看，
   不联网、不上传任何数据。放行即可。

Q：提示脚本被禁止运行？
A：右键 hanhua.ps1 → 属性 → 底部若有「解除锁定」就勾上 → 确定。
   用「安装.bat」安装的话，通常会自动处理这一步。

Q：想换回英文？
A：直接用开始菜单原来那个 Codex 图标打开就是英文。
   本工具不运行就不生效。

六、想改翻译 / 补词
用记事本打开 hanhua.ps1
（位置：C:\Users\你的用户名\AppData\Local\CodexZh\hanhua.ps1），
找到 var DICT = { ... } 这一段，照格式加一行：

    "英文原文":"中文翻译",

注意三点：
1. 前一行末尾要补一个英文逗号
2. 新词条要加在 } 这一行的【上面】，不要加在它下面
3. 保存时编码选 ANSI，不要选 UTF-8

改完存盘，双击桌面图标即可生效。

七、说明
本工具是社区汉化方案，与 OpenAI 官方无关。
Codex 更新后界面可能出现新的英文文案，属正常现象。
